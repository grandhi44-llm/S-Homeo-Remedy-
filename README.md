# SHC Remedy Finder — Android project

Runs the S Homeo Protocol (Steps 1–11) fully offline on the phone. The web app (www/) is wrapped with
Capacitor 8 into a native Android app. All data (27 MB) is bundled inside the APK; nothing leaves the phone.

## Folder layout
- `www/`              the app: index.html, app.js, engine.js, data/*.json (this is what runs)
- `android/`          the Android Studio project (generated by Capacitor, icons & splash already SHC-branded)
- `capacitor.config.json`  app id `in.shc.remedyfinder`, app name "SHC Remedy Finder"
- `node_modules/@capacitor/` only the two packages the Gradle build references (no Node.js needed to build)

## Build the APK (Android Studio, Windows/Mac/Linux)
1. Install Android Studio (free, developer.android.com/studio). First start: let it install the default SDK.
2. Android Studio → **Open** → choose the folder `android` inside this project. Wait for Gradle sync to finish
   (first time it downloads ~1 GB of build tools; needs internet).
3. Test on your phone: enable *Developer options → USB debugging* on the phone, connect by USB, press **Run ▶**.
   The app installs and opens.
4. Debug APK to share by WhatsApp/Drive: **Build → Build App Bundle(s)/APK(s) → Build APK(s)**.
   File: `android/app/build/outputs/apk/debug/app-debug.apk`. Phones must allow "install unknown apps".
5. Play Store release: **Build → Generate Signed App Bundle/APK → Android App Bundle**. Create a new keystore when
   asked (keep the .jks file and passwords safe — the same key is needed for every future update).
   Upload the `.aab` in Google Play Console (one-time developer registration fee applies — check the current terms).

## Updating the app later
- Edit the data: re-run `python3 build_data.py` (in the build folder) to regenerate `www/data/*.json`, or replace the
  JSON files directly, then copy `www/` into `android/app/src/main/assets/public/` (or run `npx cap copy android` if
  Node.js is installed). Increase `versionCode` in `android/app/build.gradle` before every Play Store upload.
- `android/app/build.gradle`: `versionCode 1`, `versionName "0.3"`.

## Protocol rules as implemented (agreed Nov 2026)
- Thermal: user selects Hot / Chilly / Ignore. Hot removes chilly remedies, Chilly removes hot remedies; remedies
  classed both or unknown are never removed. Thermal table: Publicum Generalities rubrics, overridden by SHC notes.
- Ranking: strike count only (one strike per symptom covered); grade total breaks ties.
- Organ remedy, rule (b): first a remedy named in SHC Organopathy notes as organ remedy for the keynote's organ,
  else a remedy whose organ-section rows contain the keynote's words; among candidates the one with the fewest
  Step-7 strikes wins, then the strongest organ evidence. None → "No organ remedy".
